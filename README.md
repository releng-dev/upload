# Releng.dev upload

A GitHub Action for [Releng.dev](https://releng.dev). What it does, its inputs and its outputs are in [action.yml](action.yml), and how a release uses it is in the [docs](https://releng.dev/docs).

Pin it to the commit of a version, such as `uses: releng-dev/upload@<commit> # v1.0.0`.
